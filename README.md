# Financial Economics I — Problem Set 3

Numerical solution of Question 4: consumption and portfolio choice
over a five-period horizon.

## Files

- ps3_q4.ipynb: Colab notebook containing code, explanations, and outputs.
- ps3_q4.py: Python script containing the computational code.

## Methods

Backward induction, state-space discretization, Gaussian quadrature,
interpolation, and grid search.

## Running the notebook

Open ps3_q4.ipynb in Google Colab and run all cells in order.

Dependencies: numpy, scipy, matplotlib.
